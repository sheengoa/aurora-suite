# 数据库安全规则

本目录中的每个 JSON 文件对应一个同名数据库集合。进入云开发控制台的“文档型数据库 → 集合管理 → 权限管理”，切换到安全规则后，将对应文件的完整内容粘贴并保存。

这些规则只限制小程序客户端直接访问；云函数仍使用服务端权限。应用规则前请确认集合名称与文件名完全一致，并在目标环境中逐项验证顾客查询和管理员云函数流程。

## 经营数据升级

部署当前云函数前，需先创建 `balanceLog` 集合并应用 `balanceLog.json`，否则余额支付、充值、退款和管理员调账会因流水写入失败而回滚。

历史数据无需一次性改写：缺少 `admin.isOpen` 时按营业中处理；旧订单继续使用 `status` 推导履约状态；缺少 `paymentStatus` 且状态仍为待处理的未支付订单按待支付兼容。新写入数据会完整保存支付、履约、退款和打印状态字段。
